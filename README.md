Eddie Muhia | Personal Portfolio

A responsive single-page portfolio website showcasing my skills and projects as a full stack development student at Moringa School, Kenya.

Live Demo

[View the live site](https://eddiemuhia1.github.io/eddiemuhia-portfolio/)
Features

- Full-screen hero section with a background image and introduction
- Sticky navigation bar with anchor links to each section
- About section with a photo and short bio
- Skills section rendered dynamically from a JavaScript array
- Projects section with cards built from a JavaScript array of objects (title, description, tech used, and a link to each project)
- Contact section with email and GitHub links
- Responsive layout that adapts to tablet and mobile screens using media queries

Technologies Used

- HTML5
- CSS3 (Flexbox, CSS Grid, media queries)
- JavaScript (arrays, objects, loops, DOM manipulation)
- Google Fonts
- GitHub Pages for deployment

How to Run Locally

1. Clone this repository:
   ```
   git clone https://github.com/eddiemuhia1/eddiemuhia-portfolio.git
   ```
2. Navigate into the project folder:
   ```
   cd eddiemuhia-portfolio
   ```
3. Open `index.html` in your browser. No build steps or dependencies are needed.

What I Learned

This project taught me how to combine HTML, CSS, and JavaScript into one deployed site, and how to use arrays, objects, and loops to build page content dynamically instead of hard-coding it. I also learned that small details, like matching an element's `id` exactly to its CSS selector and anchor link, can quietly break a layout.
